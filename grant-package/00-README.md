# LumenaSOL Agentic Engineering Grant Package

This folder contains the engineering handoff package for LumenaSOL's Superteam Agentic Engineering Grant application. The repository is currently in **Concept Phase**: planning, scope, and architecture documentation exist, but no production implementation, benchmarks, screenshots, tests, or deployed transaction explanation system exists yet.

## Table of Contents

| Document | Purpose |
|---|---|
| [01-Project-Brief.md](./01-Project-Brief.md) | Defines the problem, vision, target users, MVP scope, product philosophy, and differentiation. |
| [02-Architecture.md](./02-Architecture.md) | Describes the planned high-level architecture, components, data flow, deterministic decoding pipeline, AI explanation layer, and security boundaries. |
| [03-Security-Model.md](./03-Security-Model.md) | Documents the threat model, trust assumptions, privacy model, deterministic-first design, non-custodial boundaries, and known limitations. |
| [04-Implementation-Plan.md](./04-Implementation-Plan.md) | Provides a realistic four-week implementation roadmap for the planned MVP. |
| [05-Milestones.md](./05-Milestones.md) | Lists milestones, success criteria, deliverables, and a completion checklist aligned to the grant period. |
| [06-Risk-Analysis.md](./06-Risk-Analysis.md) | Identifies technical and project risks, mitigations, assumptions, and dependencies. |
| [07-Agentic-Workflow.md](./07-Agentic-Workflow.md) | Explains how solana.new and Codex are being used for planning and intended implementation support. |
| [08-Development-Transcript.md](./08-Development-Transcript.md) | Chronological engineering journal for the planning session and scope decisions, without claiming coding work that has not happened. |
| [09-Final-Summary.md](./09-Final-Summary.md) | Executive summary suitable for grant reviewers. |

## Source-of-Truth Alignment

This package is consistent with the root [README.md](../README.md), especially its status statement that LumenaSOL is a concept-phase project and that transaction decoding, the AI explanation layer, web app, and deployment do not yet exist. Existing docs under `docs/` are currently placeholders, so the root README is treated as the most complete source of truth.
